# PWM-Based Motor Speed Control

## Objective

To control the speed of a DC motor using a PWM signal generated by an Arduino Uno.

## Components

- Arduino Uno
- L293D motor driver
- DC motor
- 10 kΩ potentiometer
- 9 V battery
- Breadboard and jumper wires

## Connections

- Arduino pin 9 → L293D Enable 1
- Arduino pin 8 → L293D Input 1
- Arduino pin 7 → L293D Input 2
- L293D Outputs 1 and 2 → DC motor
- Arduino 5V → L293D pin 16
- 9 V battery positive → L293D pin 8
- Common ground → Arduino GND, battery negative, and L293D ground pins
- Potentiometer wiper → Arduino A0

## Working

The potentiometer provides an analog value to the Arduino. The Arduino converts this value into a PWM value from 0 to 255. The L293D uses this PWM signal to control the speed of the DC motor.

## Result

The motor speed changes when the potentiometer is rotated. A negative RPM value in the simulator indicates that the motor is rotating in the reverse direction.
